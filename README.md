Machine Learning Lab Experiments

This repository has the machine learning lab experiments done in Python using Jupyter Notebook / Google Colab.

Experiments
No.	Experiment	File	Dataset
1	Data Analysis (EDA) for ML	Data_Analysis_for_ML.ipynb	Titanic
2	Dimensionality Reduction using PCA	PCA_Dimensionality_Reduction.ipynb	Iris
3	Kernel Based Image Filtering	Kernel_Image_Filtering.ipynb	Sample image
4	Polynomial Linear Regression	Polynomial_Regression.ipynb	Generated data
5	K-Nearest Neighbor (KNN)	KNN.ipynb	Iris
6	Support Vector Machine (SVM)	SVM.ipynb	Iris
7	Decision Tree and Random Forest	Decision_Tree_Random_Forest.ipynb	Wine
8	K-Means Clustering	KMeans_Clustering.ipynb	Generated data
9	Hierarchical Clustering	Hierarchical_Clustering.ipynb	Generated data
10	DBSCAN	DBSCAN.ipynb	Moons data
11	Convolutional Neural Network (CNN)	CNN_MNIST.ipynb	MNIST
Libraries Used
Python 3
NumPy, Pandas
Matplotlib, Seaborn
Scikit-learn
OpenCV
TensorFlow / Keras
How to Run
Clone the repository
git clone https://github.com/<your-username>/<repo-name>.git
Install the libraries
pip install numpy pandas matplotlib seaborn scikit-learn opencv-python tensorflow
Open any notebook in Jupyter Notebook and run all cells.

Or upload the .ipynb file to Google Colab and run it there (no installation needed).
